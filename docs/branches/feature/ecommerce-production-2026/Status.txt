============================================================
🔥 GLOBAL DESIGN RULES (VERY IMPORTANT)
============================================================
1. Auth Service is the ONLY source of user data
2. Product Service stores seller_id (no user duplication)
3. Cart Service stores only product_id + variant_id (no product duplication)
4. ALWAYS use variant_id for cart & order
5. ALWAYS store price snapshot in cart
6. NEVER trust frontend price
7. Product delete → cascade delete variants + images
8. Cart uses latest price to detect price changes
9. One user = one active cart
10. Use JWT for authentication across all services
